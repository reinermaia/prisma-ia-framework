# Skill 09: Double-Loop Learning & Evolução Ontológica

## Objetivo
Retroalimentar o Grafo de Conhecimento e a biblioteca heurística local com as decisões, aprovações e correções feitas pelo auditor humano no Gate HITL.

## Mecanismo de Atualização
- Requisitos aprovados com ajuste -> Geram uma nova regra heurística refinada para futuros projetos.
- Requisitos rejeitados -> Geram uma restrição negativa no Grafo de Conhecimento, impedindo que os agentes cometam o mesmo erro no próximo ciclo.
- Redução contínua da taxa de alucinação do cluster.
